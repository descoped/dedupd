**New**

- Stores on several disks. When an app keeps its models on another disk, such as an external SSD for Ollama, add a store there under Storage › Stores. Downloads for that app go straight to it, and activating a model that is on the other disk first says how much will be copied and asks.
- Several archives, each with a name. Archive a model to the one you choose; one archive can get a copy of every download. Restore asks which store when there is more than one.
- Favorites: star models in dedupd, and bring in the models you liked on Hugging Face.
- dedupd now checks for updates once a day and offers new versions. Earlier versions cannot update themselves: this one is installed by hand, once.

**Fixed**

- Discover keeps the order you chose, and a proxy set in the environment no longer stops the app from reaching the daemon.
- An archive copy is read back before the local file is removed, and a file that appears in an app's folder while dedupd places a model is never replaced.
- The Hugging Face token is sent to Hugging Face only, and web pages cannot reach the daemon.
- Many smaller fixes to the daemon's timing, the Storage figures and the screens.
